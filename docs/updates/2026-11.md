## U-20261115-07 · 2026-11-15 · AI panels may use a local endpoint after asking · #done #security #ai

AI Code Review, CoT Code Review and Skill Send refused every endpoint on this machine or a private network, so a local model server could not be used. `validate_url` now raises `LocalAddressNeedsApprovalError` (still an `UnsafeURLError`) when every refused address is loopback or a private network's; the request thread reports it, and the panel's `LocalEndpointGate` asks once the thread has ended, naming the host and the addresses, with No as the default.
